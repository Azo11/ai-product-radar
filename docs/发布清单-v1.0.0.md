# v1.0.0 发布清单

## 1. 发布范围

- 版本：`v1.0.0`
- GitHub 建议仓库：`Azo11/ai-product-radar`
- 仓库可见性：Public
- 静态部署：GitHub Pages
- 飞书建议知识空间：`AI 智能选品助手 v1.0.0`
- 数据口径：虚拟用户研究、合成商品与测评数据、交互式 Mock 外部服务

## 2. GitHub 发布资产

- React、TypeScript、Vite Demo 源码
- `README.md`、`CHANGELOG.md`、`LICENSE`
- 八章 Demo 产品说明、数据来源策略和 Demo/生产能力对照
- 9 项 ADR、验收标准、术语表和集成准备状态
- 5 份飞书模拟知识资产和 Mock 写入载荷
- 40 条合成测评集、人工评审模板和 7 类 Bad Case
- 5 张真实 Demo 截图
- GitHub Pages 构建和部署工作流

不发布 `node_modules/`、`dist/`、Hallmark 日志、Playwright 临时文件、环境变量或任何凭据。

原始 `CSV` 和 `JSONL` 文件作为测评文档附件一并上传，避免飞书表格成为唯一数据源。

## 4. 飞书证据边界

所有总览、Demo 产品说明、模拟资产和测评文档必须明确说明：

- 当前没有真实用户访谈、经营数据或运营专家标签。
- 当前没有真实 Dify、Hermes、模型或飞书 Demo 集成。
- 飞书模拟资产是目标知识库结构和字段映射，不是历史业务记录。
- 40 条测评案例由产品经理合成规则生成，只能证明资产结构和分数可复算。
- AI 提供参考意见，运营人员作出最终决策。

## 5. 发布前验证

- `npm test`
- `npm run eval:validate`
- `npm run build`
- Markdown 本地链接检查
- 凭据与私钥扫描
- 桌面 1440px 和移动端 390px 浏览器验收
- PDF 下载后 A4 渲染检查

## 6. 发布后验证

### GitHub

- 回读仓库默认分支、版本文件和提交内容。
- 确认 GitHub Actions 构建、测试和部署成功。
- 打开 Pages URL，验证标题、图片、交互和 PDF 下载。
- 创建并回读 `v1.0.0` tag 与 GitHub Release。

### 飞书

- 回读知识空间目录和每个文档标题。
- 回读正文长度、版本和关键证据边界。
- 核对合成测评案例 40 条、人工评审模板 40 条、Bad Case 7 条。
- 删除 Base 自动生成的空白记录后重新计数。
- 返回可访问的知识空间、Demo 产品说明和测评资产链接。

## 7. 回滚基线

当前仓库尚无首个提交、远端、tag、Release 或线上部署，因此首次发布前不存在可恢复的上一版本。若发布失败，不删除已创建的远端资源；停止后记录失败步骤，并在修复后继续完成回读验证。
