# V1 合成测评方案与资产校验结果

> 证据等级：合成测评方法演示，不是模型效果或业务效果。
>
> 当前没有真实运营数据、真实模型运行输出或运营专家标注。本文只报告已经执行的数据与规则校验，不使用预设百分比冒充模型准确率。

## 1. 测评目的

V1 测评需要分别回答四类问题：

1. 规则层：六维分数和总分能否按固定权重复算？
2. AI 输出层：推荐解释是否引用输入证据，并披露风险和不确定性？
3. 人机边界：输出是否避免热销、合规、供应和利润保证，并保留人工最终决策？
4. 产品效果层：候选排序是否与有经验运营人员的研究优先级判断一致？

当前只完成第 1 类的数据资产校验，并为第 2–4 类准备了测评字段和人工评审模板。

## 2. 测评集组成

| 项目 | 设计 |
| --- | --- |
| 样本数量 | 40 个合成商品案例 |
| 类目 | 家居收纳、厨房小工具、宠物用品、美妆工具、户外配件，每类 8 个 |
| 校准集 | C001–C028，共 28 条 |
| 留出集 | C029–C040，共 12 条 |
| Bad Case | BC-001–BC-007，共 7 条 |
| 输入字段 | 趋势幅度与持续时间、传播分、竞品价格带、采购与物流成本、重量、供应商数量、缺失字段、六维分数和证据记录 |
| 参考标签 | 优先研究、建议研究、谨慎研究 |
| 标签来源 | 产品经理制定的合成规则，不冒充运营专家判断 |

完整文件位于 `docs/evaluation/datasets/`，使用方式见 `docs/evaluation/README.md`。

## 3. 临时评分权重

| 维度 | 临时权重 |
| --- | ---: |
| 需求增长 | 25% |
| 传播潜力 | 20% |
| 参考利润空间 | 20% |
| 供应稳定性 | 15% |
| 物流友好度 | 10% |
| 合规安全度 | 10% |

竞品信息不是独立维度，只为需求、内容、价格和同质化判断提供证据。任何维度都不设置一票否决，但缺失和高风险必须影响置信度并在报告中披露。权重仍需通过运营专家标注的校准集确认。

## 4. 案例期望输出

每条 JSONL 案例包含：

- 可复算的 `expected.score` 与三档 `recommendation_level`
- 推荐必须引用的结构化证据编号
- 推荐必须披露的风险或不确定性
- 禁止出现的无依据承诺
- 证据置信度和人工最终决策要求
- 明确的 `product_manager_synthetic_rule_v1` 标签来源

## 5. 当前已运行的资产校验

运行命令：

```bash
npm run eval:generate
npm run eval:validate
```

| 校验项 | 已验证结果 | 代表含义 |
| --- | ---: | --- |
| 案例数量 | 40 | 数据文件与方案数量一致 |
| 数据划分 | 28 / 12 | 校准集与留出集边界固定 |
| 类目覆盖 | 5 类，每类 8 条 | 基础类目分布均衡 |
| 三档标签覆盖 | 3 / 3 | 每个推荐等级都有案例 |
| 分数可复算 | 40 / 40 | 固定输入与权重得到相同总分 |
| Bad Case | 7 | 关键失败场景已形成回归资产 |
| 飞书 Mock 资产 | 5 | 每个载荷都有本地源文档且无真实 `document_id` |

这些是脚本真实运行的结构与规则校验结果，不代表模型推荐准确、专家认可或业务有效。

## 7. Bad Case 覆盖

| 编号 | 场景 | 核心预期 |
| --- | --- | --- |
| BC-001 | 短期热度峰值 | 不把单点暴涨描述为持续增长 |
| BC-002 | 合规信息缺失 | 披露缺失，不声称已合规 |
| BC-003 | 供应商样本过少 | 降低置信度，不声称供应稳定 |
| BC-004 | 竞品价格带离散 | 不使用单一参考价作确定定价 |
| BC-005 | 趋势与成交信号冲突 | 展示冲突并要求人工复核 |
| BC-006 | 电池运输 | 披露物流与资料核验要求 |
| BC-007 | 结构或使用安全敏感 | 不弱化安全测试和警示要求 |

## 8. 正式验证条件

只有满足以下条件后，才能发布真实模型效果：

1. Dify 工作流、Hermes 执行节点、评分服务和模型分析实际运行。
2. 每次运行保存数据快照、提示词、模型版本、输出和日志。
3. 至少两名有目标市场经验的运营人员独立标注校准集和留出集。
4. 标签分歧有明确处理规则，留出集未参与调参。
5. 指标由实际输出计算，并保留失败案例。
6. 模型指标与真实销量、利润等业务效果分开表述。
