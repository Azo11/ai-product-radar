# AI 智能选品助手 Demo 产品说明结构

> 本文件为早期结构提纲。完整说明见 [`AI智能选品助手-Demo产品说明.md`](./AI智能选品助手-Demo产品说明.md)。
>
> 本阶段采用虚拟用户模拟和合成业务数据进行探索性验证，用于形成产品假设、验证功能闭环和展示技术方案，不代表真实用户调研、真实平台接入或业务效果。

## 01 项目背景

- TikTok Shop 美国站新手卖家的选品流程与信息搜集成本
- 项目目标、范围和 V1 聚焦理由
- 当前假设、证据来源和项目限制

## 02 用户研究

- 虚拟用户画像：新手个体卖家、人工表格选品小团队
- 模拟任务访谈与用户旅程
- 核心痛点：商品信息查询和竞品整理耗时
- 需求假设、待验证问题和研究限制

## 03 产品方案

- 核心场景与用户闭环
- 候选商品列表、单品详情、多品对比和报告
- 六维评分与竞品参考定位
- AI、系统和用户的职责边界
- 正常流程、失败流程与降级策略

## 04 AI 架构设计

- V1 交互式 Mock 架构
- 真实生产应用目标架构
- Dify 编排、Hermes 执行、规则服务、模型和飞书的职责
- 数据流、权限、审批、审计、失败与降级
- Mock 能力与生产能力对照表

## 05 原型设计

- 信息架构与关键页面
- 创建任务、候选列表、商品详情、对比、报告和执行记录
- 交互状态、空状态、错误状态和移动端适配

## 06 Demo 展示

- 公开访问地址和操作主线
- 真实交互与 Mock 节点说明
- 飞书知识库模拟文档、结构化写入载荷与本地 PDF 报告
- 正常流程和 Bad Case 演示
- GitHub 仓库与运行方式

## 07 效果评估

- 40 条合成测评集：28 条校准集、12 条留出集
- 7 类 Bad Case 与运营专家评审模板
- 规则可复算、证据一致、风险披露和流程完整性
- 已运行的数据资产校验与待计算的模型效果指标
- 不能证明的结果与未来真实验证方案

## 08 后续规划

- V1 真实数据与服务集成路径
- V2 AI Listing 优化助手
- V3 AI 运营分析助手
