# Demo 与生产能力对照

> 本表是作品集的统一能力口径。所有公开介绍、飞书文档和面试讲解均应遵循。

## 状态定义

| 状态 | 含义 |
| --- | --- |
| 已实现 | 当前代码真实执行，可通过测试或浏览器复现 |
| 已模拟 | 使用合成数据、预生成内容或 Mock 状态展示交互 |
| 待验证 | 生产方案已设计，但尚未完成真实接入或效果验证 |

## 可以公开表述

- 设计并实现了公开交互式 AI 选品 Demo。
- 真实实现筛选、排序、评分、收藏、对比、重算、状态流转和 PDF 下载。
- 设计了以 Dify 为编排层、Hermes 为执行层、飞书为知识库的生产目标架构。
- 建立了 40 条合成测评集、人工评审模板和 7 类 Bad Case。
- 所有推荐用于辅助研究，最终决定由运营人员作出。

## 不可以公开表述

- 已接入 TikTok Shop、1688、第三方选品平台或真实经营数据。
- 已使用 Dify 编排真实工作流或由 Hermes 采集市场数据。
- 已调用真实大模型生成当前 Demo 结论。
- 已将 Demo 报告真实保存到飞书企业知识库。
- 已获得运营专家认可，或提升销量、利润、转化率和选品效率。

## 发布验收规则

1. Demo 截图保留商品素材和证据来源的模拟标识。
2. 飞书模拟资产与测评集一起发布，并保留数据边界说明。
3. 真实外部集成只有在保存运行记录和回读证据后才能改为“已实现”。
4. 模型指标、产品效率和业务效果分别报告，不互相替代。
