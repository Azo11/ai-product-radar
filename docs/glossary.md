# 领域术语表

| 术语 | 定义 | 边界说明 |
| --- | --- | --- |
| 潜力品 | 在目标类目中，基于需求增长、传播潜力、参考利润空间、供应、物流和合规等信息，值得进入人工深入研究阶段的商品 | 不等于必然热销，也不等于系统自动决定上架 |
| 选品任务 | 用户以预设或自定义类目为必填条件，并可附加经营约束后发起的一次分析 | 类目由用户定义，Hermes 只执行采集与归类 |
| 趋势信号 | 用于反映商品需求或内容热度变化的结构化指标 | Demo 中均为模拟数据 |
| 候选商品 | 被趋势发现流程召回、等待六维评估的商品 | 进入候选列表不代表最终推荐 |
| 六维评估 | 对需求增长、传播潜力、参考利润空间、供应稳定性、物流难度、合规风险进行加权分析 | 参考利润空间使用竞品价格带中位值进行早期测算，权重需通过专家标注测评集验证 |
| 竞品参考价 | 从同类竞品价格样本中提取价格带，并默认使用中位值进行情景测算 | 不等于最终定价，且未完整包含平台佣金、营销和退货成本 |
| 竞品参考 | 为需求、价格带、内容打法和同质化判断提供辅助证据的竞品信息 | 不作为独立评分维度 |
| 推荐意见 | AI 基于六维信息生成的排序、理由与风险提示 | 仅供参考，不替代运营人员决策 |
| 专家标注 | 有经验的运营人员对样本是否值得进一步研究作出的独立判断 | 当前尚未获得，不能用产品经理生成的标签替代 |
| 合成测评 | 使用虚构商品案例、预设标签和示例结果演示评测方法 | 不能证明模型效果、专家认可或业务收益 |
| 模拟数据 | 为演示产品流程而构造的市场、商品、竞品和供应链样本 | 不代表真实平台数据或生产接入能力 |
| 候选池 | 用户收藏并准备进一步对比或研究的商品集合 | 加入候选池不代表决定采购或上架 |
| 推荐等级 | 将潜力评分转化为便于扫描的研究优先级 | 表示研究顺序，不表示销售结果承诺 |
| 选品分析报告 | 汇总商品评分、证据、竞品参考、经营测算和风险意见的结构化输出 | 由用户确认后生成，不替代最终决策 |
| Dify 工作流 | 编排数据获取、校验、评分、模型分析、人工确认和资产发布的运行流程 | 不承担业务数据库或确定性评分职责 |
| Hermes 执行层 | 在受控权限下调用工具并读取、采集、清洗和汇总数据的执行组件 | V1 只处理本地模拟数据，真实平台采集属于后续能力 |
| 知识资产 | 经用户确认后保存的候选清单、单品分析、竞品摘要和选品报告 | 飞书保存可读副本，业务系统保留结构化记录 |
| 工作流运行 | 一次 Dify 编排过程及其节点输入、输出、状态和错误记录 | 用于追踪、评测和失败定位 |
| 虚拟用户模拟 | 基于预设角色和场景生成的探索性用户反馈 | 用于推演假设，不等于真实用户访谈 |
| 待验证假设 | 当前由虚拟研究或产品判断形成、尚未获得真实证据支持的结论 | 后续需要真实访谈、可用性测试或业务数据验证 |
| 降级结果 | 外部服务失败或数据不完整时，系统基于已验证信息提供的有限结果 | 必须展示缺失能力和不确定性 |
| 幂等键 | 用于识别同一次业务请求、防止重复创建任务或文档的唯一标识 | 重试时复用，不把重复调用视为新业务 |
| Bad Case | 未达到预期的输入、输出或交互案例 | 需要记录原因、影响、修复和复测状态 |
| 交互式 Mock | 使用预设数据和结果，但由真实用户操作驱动规则计算、状态变化和异常恢复的 Demo | 不等于真实外部服务集成，也不能表述为静态截图 |
