# ADR-004: 虚拟用户研究与 Demo 证据口径

- 状态：已确认
- 日期：2026-07-23

## 背景

当前无法接触目标用户，也没有真实平台数据、经营数据或运营专家标注。项目的主要目的，是通过可交互 Demo 演示产品能力并验证方案逻辑，而不是证明市场需求或业务收益。

## 决策

1. 用户研究章节采用虚拟用户画像、模拟任务访谈和用户旅程假设。
2. 市场、商品、竞品、供应链与测评数据均可使用虚拟数据演示。
3. 所有模拟材料必须清楚标注，不伪装成真实访谈、真实平台数据或专家结论。
4. 用户研究输出用于形成需求假设和原型方向，不作为真实用户验证证据。
5. Demo 用于验证功能闭环、信息结构、规则可复算性、AI 解释边界和技术链路。
6. 效果评估只呈现合成案例中的方法演示，并列出后续真实验证计划。

## Demo 统一表述

建议使用以下统一说明：

> 本阶段采用虚拟用户模拟和合成业务数据进行探索性验证，用于形成产品假设、验证功能闭环和展示技术方案，不代表真实用户调研、真实平台接入或业务效果。

## 禁止表述

- “访谈了若干名 TikTok Shop 卖家”，除非真实发生并有记录。
- “专家评审证明推荐准确”，除非真实专家完成独立标注。
- “帮助用户提升销量、利润或选品效率”，除非有真实测量数据。
- 将合成案例中的模拟指标写成线上实测结果。

## 后果

- 第 02 章“用户研究”需要增加“研究限制”和“待验证假设”。
- 原型与 Demo 页面需要持续显示模拟数据标识。
- 第 07 章“效果评估”需要分开呈现模拟结果、目标指标和未来真实验证方案。
