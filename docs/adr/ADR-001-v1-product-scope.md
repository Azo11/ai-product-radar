# ADR-001: V1 产品范围与证据边界

- 状态：已确认
- 日期：2026-07-23

## 背景

项目用于 AI 产品经理作品集，目标是帮助中小跨境卖家降低选品决策中的信息搜集成本。目标用户当前通常通过 TikTok 热门内容发现线索，再查询商品情况、寻找竞品、核对货源与利润，最后依赖人工经验判断。其中，商品信息查询和竞品整理耗费大量时间，但直接决策价值较低。

## 决策

1. V1 聚焦 TikTok Shop 美国站。
2. 主要用户是缺乏选品经验的个体卖家；次要用户是依赖人工表格和经验选品的小团队。
3. V1 覆盖潜力品发现、候选品评估、单品判断和报告输出，但第一优先级是从市场趋势中发现值得进一步研究的商品。
4. 用户创建选品任务时必须选择预设类目或输入自定义类目；类目由运营人员定义，Hermes 只按该关键词采集、清洗和归类数据。采购成本上限、重量、禁售品类和供应方式等条件可选。
5. 推荐依据包含六个维度：需求增长、传播潜力、参考利润空间、供应稳定性、物流难度、合规风险。
6. 六个维度采用加权评分，具体权重通过测评集验证后确定。
7. 竞品信息不是独立评分维度，只作为需求、价格、内容打法和同质化判断的参考证据。
8. 不设置一票否决项。系统展示风险与参考意见，由运营人员或卖家作最终选择。
9. V1 用户闭环为：选择类目、查看潜力品列表、查看单品证据、多商品对比、人工确认、生成报告。

## 信息架构基线

### 候选商品列表

列表展示商品名称、图片、类目、潜力评分、推荐等级、六维评分摘要、需求趋势、传播潜力、采购成本、竞品参考价格带、参考利润空间、主要风险、推荐理由和模拟数据标识。

列表支持排序、筛选、收藏、选择 2 至 4 个商品进行对比，以及进入商品详情。

### 商品详情

详情页包含推荐结论、需求增长、传播潜力、利润与供应链、竞品参考、物流与合规风险六个部分。竞品参考价默认取竞品价格带中位值，仅用于早期情景测算，不等于最终定价。用户可以加入候选池、对比商品、调整参考价和采购成本、查看评分依据、标记研究结论，以及生成选品分析报告。

以上结构是原型基线，后续根据原型走查结果调整。

## Demo 交互范围

V1 Demo 需要走通以下完整链路：

1. 创建选品任务。
2. 查看 Dify 工作流与 Hermes 执行过程。
3. 浏览候选商品列表。
4. 查看单品详情与评分证据。
5. 选择多个商品进行对比。
6. 调整经营参数并重新测算。
7. 由用户确认是否继续研究。
8. 生成并下载本地 PDF 报告。
9. 将确认后的选品分析保存到飞书企业知识库。

上述步骤需要真实交互和状态变化，不能只用静态页面或定时动画模拟成功。

## AI 与人工边界

- AI：整理模拟市场信号、生成六维分析、解释评分并给出推荐意见。
- 系统：执行结构化校验、保存分析记录、展示证据与风险提示。
- 用户：核验关键信息并作最终选品决策。

## 证据边界

1. Demo 使用模拟数据，不宣称已接入 TikTok、TikTok Shop、第三方选品平台、1688 或企业 ERP。
2. 当前没有真实经营数据，也无法邀请目标市场运营专家参与标注。现阶段仅使用产品经理制定的合成案例演示评测方法。
3. 合成测评不能证明推荐结果与专家判断一致，也不能证明提升真实销量、利润、成交率或任务效率。
4. 后续只有在获得真实专家独立标注并实际运行系统后，才能发布真实评测结果。

## 后果

- Demo 在商品素材、详情和报告等证据位置清晰标注“模拟数据”，不在页面顶栏重复展示项目说明。
- 效果评估先定义合成案例、固定规则与示例指标，并明确标注为非实测结果；后续补充专家标注规范和一致性指标。
- 生产版的数据接入、实时性和平台授权属于后续规划，不作为 V1 已实现能力。
