# ADR-002: AI、系统与用户的职责边界

- 状态：已确认
- 日期：2026-07-23

## 背景

V1 需要综合市场、内容、利润、供应、物流与合规信息，但 Demo 使用模拟数据，且推荐结果仅作为人工决策参考。若把确定性计算、风险提示和最终决策都描述为 AI 能力，会降低结果的可解释性与 Demo 可信度。

## 决策

### 系统规则负责

- 毛利率与费用计算
- 物流指标换算
- 输入和基础数据校验
- 六维分数的加权汇总与商品排序
- 保存参数、证据、结果和用户操作记录

### AI 负责

- 总结趋势信号
- 提炼竞品参考信息
- 分析商品的短视频传播潜力
- 解释评分结果
- 生成风险提示与选品分析报告

### 用户负责

- 核验关键证据和参数
- 调整经营假设并重新测算
- 决定商品是否进入下一步研究
- 作出采购、上架和运营决策

## 约束

1. AI 不修改基础数据和确定性计算结果。
2. AI 必须标明缺失信息和不确定性，不能用生成内容补齐不存在的事实。
3. AI 不直接执行采购、上架或运营动作。
4. 所有 Demo 分析均建立在模拟数据上，界面与报告必须保留数据来源标识。

## 后果

- AI 输出需要引用对应的结构化证据。
- 六维评分必须可以脱离语言模型独立复算。
- 评分、解释、人工选择和参数修改需要保留版本记录，以支持评测和复盘。
