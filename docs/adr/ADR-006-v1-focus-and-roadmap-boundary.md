# ADR-006: 聚焦 V1 与后续版本边界

- 状态：已确认
- 日期：2026-07-23

## 决策

当前阶段只设计、实现和验证 V1 AI 选品助手。V2 至 V4 仅用于作品集“后续规划”章节，不进入当前原型、Demo、接口或验收范围。

## 路线图

| 版本 | 产品能力 | AI 权限边界 | 当前状态 |
| --- | --- | --- | --- |
| V1 AI 选品助手 | 发现和评估潜力品，生成候选池与选品报告 | AI 分析和推荐，用户最终决定 | 当前唯一实施范围 |
| V2 AI Listing 优化助手 | 基于已确认商品生成标题、卖点、关键词和内容建议 | 用户审核后才能发布 | 仅路线图 |
| V3 AI 运营分析助手 | 分析流量、转化、库存和内容表现，输出诊断与行动建议 | 只建议，不自动执行 | 仅路线图 |
| V4 自动化运营 Agent | 根据目标制定计划并调用工具执行运营任务 | 在权限、预算和审批范围内受控执行，可回滚和人工接管 | 仅路线图 |

产品能力按“辅助发现、辅助生成、辅助诊断、受控执行”逐级提升。

## 后果

- V1 不实现 Listing 生成、店铺经营分析或自动运营动作。
- 不为未实施版本提前建设无明确复用价值的页面和服务。
- V2 至 V4 的详细需求应在 V1 验证完成后重新调研和立项。
