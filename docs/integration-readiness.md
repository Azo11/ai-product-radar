## 当前结论

V1 不需要开通 Dify、配置 Hermes Provider 或核验飞书权限。对应节点全部使用明确标识的交互式 Mock。未来启动真实集成时，再重新检查本表状态。

## 未来真实集成的成本基线

- V1 不产生 Dify、Hermes 或模型调用费用；未来真实集成前重新核对各服务当期价格和免费额度。
- 模型 API 调用费用由已有模型供应商单独计费，需要设置调用预算和测试上限。
- 免费套餐的日志保留有限，关键运行证据需要及时导出或截图，工作流需要导出 DSL 版本。
