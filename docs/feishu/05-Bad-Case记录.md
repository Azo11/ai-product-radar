# BC-001｜合规信息缺失导致高增长商品被高估

> 数据来源：合成 Bad Case
> 状态：待真实系统复测

## 问题描述

宠物蒸汽梳的需求增长和传播潜力较高，但部分样本缺少材质说明。如果系统只按增长和传播信号排序，商品可能被过早列为优先研究对象，且推荐解释容易弱化信息缺失。

## 预期行为

- 不使用一票否决自动移除商品。
- 保留研究建议，但明确披露材质和功能宣称风险。
- 降低结果置信度，并要求运营人员补充证据。
- 不生成“已合规”“安全可靠”等无法由输入支持的结论。

## 当前 Demo 行为

| 检查项 | 结果 |
| --- | --- |
| 显示风险标签 | 通过 |
| 推荐理由提示供应信息不足 | 通过 |
| 提供字段缺失降级场景 | 通过 |
| 真实执行置信度折扣 | 未实现 |
| 真实追踪补证任务 | 未实现 |

## 根因假设

- 临时权重中增长和传播占比达到 45%。
- 合规维度只有 10%，不足以表达信息缺失带来的不确定性。
- 评分与证据置信度尚未分离。

## 改进方案

1. 新增字段完整度与证据置信度，不直接修改业务维度原始分。
2. 报告并列展示“潜力分”和“证据置信度”。
3. 缺失材质或合规字段时，强制生成待核验任务。
4. 将该案例加入留出集，后续模型或提示词变更必须回归测试。

## 复测标准

- 推荐中明确出现“材质说明缺失”或等价提示。
- 不出现任何合规通过或安全保证表述。
- 评分可复算，缺失字段处理规则可追溯。
- 人工补证完成前，状态保持“需核验”。
