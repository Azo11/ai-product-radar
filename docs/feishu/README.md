# 飞书企业知识库模拟资产

> 证据等级：本地模拟文档，未真实写入飞书。

本目录模拟 V1 中“保存到飞书企业知识库”后形成的可读知识资产，用于 Demo 展示、作品集截图和后续真实集成的字段对齐。市场、商品、竞品、供应链和 AI 结论均为合成数据。

## 建议知识库结构

```text
AI 选品雷达
├── 01 选品任务
│   └── TASK-20260723-001｜TikTok Shop 美国站潜力品研究
├── 02 候选商品
│   └── 2026-07-23｜候选商品清单
├── 03 单品分析
│   └── 便携化妆刷套装｜单品分析
├── 04 对比报告
│   └── 便携化妆刷套装 vs 宠物蒸汽梳
└── 05 Bad Case
    └── BC-001｜合规信息缺失
```

## 资产清单

| 文件 | 对应飞书资产 | 用途 |
| --- | --- | --- |
| `01-选品任务记录.md` | 选品任务文档 | 记录输入条件、执行摘要和任务状态 |
| `02-候选商品清单.md` | 候选池文档 | 集中查看候选商品及人工判断 |
| `03-单品分析-便携化妆刷套装.md` | 单品分析文档 | 保存评分、证据、风险和待验证项 |
| `04-选品对比报告.md` | 对比报告文档 | 支持运营人员比较与会审 |
| `05-Bad-Case记录.md` | Bad Case 文档 | 沉淀失败、影响、恢复和复测结果 |
| `mock-feishu-assets.json` | Mock 写入载荷 | 对齐未来飞书写入接口的结构化字段 |

## Demo 与生产映射

| 环节 | 当前 Demo | 真实生产应用 |
| --- | --- | --- |
| 文档生成 | 前端固定模板和本地数据 | 服务端按任务快照生成版本化文档 |
| 保存动作 | 前端展示 Mock 状态 | 服务端以用户或应用身份调用飞书 API |
| 保存结果 | 本地模拟文档 | 返回 `document_id`、知识空间节点和访问链接 |
| 回读验证 | 未实现 | 写入后读取标题、版本和关键字段进行核验 |
| 权限 | 无登录公开体验 | 企业租户、RBAC、最小权限和审计日志 |
| 失败恢复 | 预设失败场景 | 幂等键、限次重试、死信记录和人工补偿 |

## 真实接入时必须新增的字段

- `tenant_id`、`operator_id`、`task_id`、`document_id`
- 写入身份、知识空间节点、权限范围
- 模板版本、数据快照版本、评分版本、模型版本
- 幂等键、写入时间、回读时间、失败原因和重试次数
